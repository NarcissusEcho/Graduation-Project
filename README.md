# 麦克纳姆轮 AGV 小车毕业设计

## 项目简介

本项目为毕业设计，目标是设计并实现一台采用麦克纳姆轮的全向移动 AGV（Automated Guided Vehicle）小车。小车通过四个独立驱动的麦克纳姆轮实现前进、后退、横向移动、斜向移动以及原地旋转等运动方式。

## 当前方案

### 机械结构

- 采用四轮麦克纳姆轮底盘结构。
- 麦克纳姆轮数量：4 个。
- 麦克纳姆轮直径：100 mm。
- 每个车轮由一台步进电机独立驱动。

### 电机控制板

- 每个电机控制板的主控芯片：STM32G0B1VBT6。
- 每个车轮配置一块独立的电机控制板，共计四块。
- 每块电机控制板计划配置一颗 MT6835 磁编码器芯片，用于检测对应电机的转子角度和运动状态。
- 电机控制板负责接收 CAN 指令，并完成对应步进电机的脉冲、方向、使能、角度采集及运行状态管理。
- 整车级主控用于运动学计算、四轮速度协调和整车状态管理，具体方案目前尚未确定。

### 电机与驱动

- 驱动电机：步进电机。
- 步进电机驱动芯片：DRV8424。
- 角度检测芯片：MT6835 磁编码器。
- 四路步进电机采用分立控制方案，每路电机均配置独立的驱动与控制信号。
- MT6835 为电机控制提供转子角度反馈，可用于状态监测以及后续闭环控制功能的开发。
- 整车级主控根据麦克纳姆轮运动学模型计算各车轮的转动方向和目标速度，再将指令发送给各电机控制板。

### 通信方式

- 通信总线：CAN。
- 通信协议：基于 CAN 总线设计应用层通信协议。
- 整车级主控与四块电机控制板之间通过 CAN 总线通信。
- CAN 通信用于电机控制指令、运行状态、故障信息和调试数据的传输。

## 主要设计内容

1. 四轮麦克纳姆轮底盘及机械结构设计。
2. 基于 STM32G0B1VBT6 的电机控制板最小系统与外围电路设计。
3. 基于 DRV8424 的步进电机驱动电路及四块独立电机控制板设计。
4. MT6835 磁编码器接口、转子角度采集及反馈功能设计。
5. 麦克纳姆轮运动学建模与四轮速度分配。
6. 步进电机脉冲、方向和使能信号控制。
7. CAN 总线硬件接口及应用层通信协议设计。
8. 整车运动控制、状态监测与故障处理程序设计。
9. 样机调试与运动性能测试。

## 电源方案

电源设计已整理到 [POWER_DESIGN.md](POWER_DESIGN.md)：24 V 直接供给 DRV8424，使用 TPSM365R6V3 生成 3.3 V，STM32G0B1、MT6835 和 3.3 V CAN 收发器共用 3V3_LOGIC，不设置 5 V 电源轨。该方案按 24 V 稳压/受控母线设计，若电池再生或浪涌使 VM 超过 33 V，需要增加过压钳位或改用 48 V 等级驱动器。
